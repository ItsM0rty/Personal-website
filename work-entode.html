Case study 02, 2026

Entode

An architect-first AI app generator. I turn a natural-language spec into a verified, production-ready backend, with a compiler that keeps the architecture explicit and tests that check the running app.

Role
Solo. Design, compiler, evaluator, and UI.
Stack
Python, FastAPI, SQLAlchemy, pytest, React, React Flow
Output
Auth, relational data, row-level permissions, encrypted fields, and REST APIs
Code
Private. Happy to walk through the architecture.

01

The idea

A short request can describe an app, but it cannot settle every decision about data, access, and behavior. I wanted the generated backend to have an architecture I could inspect before treating the code as finished.

Entode holds that architecture in one internal representation. The ERD, business-logic and state-machine view, generative design surface, and running app all come from it. A change to the design reaches every view without a separate copy to keep in sync.

02

The pipeline

  1. Propose. One AI turns the request into chunks of the app architecture. I review each step before the compiler proceeds.
  2. Compile. The compiler turns the reviewed proposal into the backend structure and contracts.
  3. Write. A second AI writes code with only the narrow context needed for its task.
  4. Evaluate. A deterministic pytest evaluator checks the generated result. Neither model grades its own work.

The pipeline can recover from provider failures and resume its chunked proposal. Human review stays in the loop at every step, including after recovery.

03

The test that changed the result

The running app had to prove the wiring.

End-to-end evaluation

Every earlier check passed. One route was still wired wrong.

A generated backend passed the other checks in the pipeline, but an end-to-end test found a real cross-route wiring defect. The individual pieces looked correct; the request path through the running app was not.

That case is why the evaluator exercises behavior across routes, rather than accepting code shape or isolated route checks as proof. The model that wrote the code does not decide whether the result passes.

04

What it produced

From the sentence "build a basic social network," Entode generated a backend with auth, a relational data model, RBAC with row-level permissions, encrypted fields, and a REST API. It passed 100% of a 250+ test compiler and contract suite on the first attempt, at $0.0146 in inference cost.

I also validated the pipeline against six real-world archetypes: marketplace, CRM, booking, helpdesk, LMS, and ticketing.
